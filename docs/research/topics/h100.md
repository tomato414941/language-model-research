# H100

H100 1枚を、実験の基準の GPU にしている。理由と料金の比較は [Vast の料金](../experiments/gpu-prices.md)、速さは [基準の学習](../experiments/baseline.md) を見る。

- 速さ：そのままの nanoGPT（9,125万パラメータ）で約63万トークン/秒。
- 使える工夫：[FlashAttention-3](../sources/flash-attention.md) と [FP8](../sources/transformer-engine.md)。Ada 以降の GPU なら FP8 は使える。ただし12層ではかえって遅いという結果があり、今の規模で効くとは限らない（speed.md）。
- [autoresearch](../sources/autoresearch.md) も H100 で確かめている。公開の結果と比べやすい。

GPU の性能と FP8 の調査は `language-model` の [h100.md](https://github.com/tomato414941/language-model/blob/main/docs/research/topics/h100.md)、[fp8.md](https://github.com/tomato414941/language-model/blob/main/docs/research/topics/fp8.md) を見る。

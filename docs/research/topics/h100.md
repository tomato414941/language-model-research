# H100

In the view as of 2026-10, one H100 is the baseline GPU for experiments. For the reasons and the price comparison see [Vast's prices](../experiments/gpu-prices.md); for the speed, see [the baseline's training](../experiments/baseline.md).

Rented GPUs are Ada or later, whatever the provider. FP8 is available only from Ada on, so drawing the line here makes the techniques we try usable the same way on every GPU. Ampere GPUs such as the A100 and the RTX 3090 are not used. If FP8 turns out not to help at the current scale, the reason for drawing this line weakens.

- Usable techniques: [FlashAttention-3](../sources/flash-attention.md) and [FP8](../sources/transformer-engine.md). FlashAttention-3 did not make the first bundle's shape faster (attention-kernel.md). On Ada or later GPUs, FP8 can be used. But there is a result that it is actually slower at 12 layers, so it may not help at the current scale (speed.md).
- [autoresearch](../sources/autoresearch.md) also verifies on the H100. This makes comparison with public results easy.

For the survey of GPU performance and FP8, see `language-model`'s [h100.md](https://github.com/tomato414941/language-model/blob/main/docs/research/topics/h100.md) and [fp8.md](https://github.com/tomato414941/language-model/blob/main/docs/research/topics/fp8.md).

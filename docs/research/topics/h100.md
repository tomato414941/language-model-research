# H100

2026-10時点の見方では、H100 1枚を実験の基準の GPU にする。理由と料金の比較は [Vast の料金](../experiments/gpu-prices.md)、速さは [基準の学習](../experiments/baseline.md) を見る。

借りる GPU は、業者を問わず Ada 以降にする。FP8 が使えるのは Ada 以降なので、ここで線を引くと、試す工夫がどの GPU でも同じように使える。A100 や RTX 3090 など Ampere の GPU は使わない。FP8 が今の規模で効かないと分かれば、この線を引く理由は弱くなる。

- 使える工夫：[FlashAttention-3](../sources/flash-attention.md) と [FP8](../sources/transformer-engine.md)。FlashAttention-3 は最初の束の形では速くならなかった（attention-kernel.md）。Ada 以降の GPU なら FP8 は使える。ただし12層ではかえって遅いという結果があり、今の規模で効くとは限らない（speed.md）。
- [autoresearch](../sources/autoresearch.md) も H100 で確かめている。公開の結果と比べやすい。

GPU の性能と FP8 の調査は `language-model` の [h100.md](https://github.com/tomato414941/language-model/blob/main/docs/research/topics/h100.md)、[fp8.md](https://github.com/tomato414941/language-model/blob/main/docs/research/topics/fp8.md) を見る。

# Engram

直前の数トークンをハッシュして、学習する表を引く方法。2026-11時点の見方では、完全な形は今の規模で試す優先度が低く、簡単な2トークンの表だけを小さい候補に残している。測った結果ではない。

- **大規模：** [Engram の論文](../sources/engram.md)では、同じ計算量で MoE より検証 loss が0.7%と1.5%低い。計算量を約1.14倍と約1.3倍にしたのと同じくらい（自分たちの換算）。最小の実験でも今の基準の約730倍の計算量で、loss の実験はすべて MoE の上。
- **追試：** [Tokenizer-Agnostic Engram](../sources/tokenizer-agnostic-engram.md) では、ベンチマークの平均は上がったが、wikitext の BPB は0.861から0.919へ悪化した（各1回）。物差しが BPB なので注意が要る。
- **小さい規模：** nanochat の LOG（2026-01-27、28）では、完全な形の改善はわずかで、ゲートも3トークンも効かず、前半の層だけに入れると悪化した。一番良かったのは2トークンの表を全層に足す形で、12層では勝ったが、25層では時間で比べると効果が消えて取り除かれた。Marin では約0.2%（[bigram hash のメモ](https://github.com/tomato414941/language-model/blob/main/docs/research/topics/bigram-hash-embedding.md)）。
- **説明の弱いところ：** 12層の最後の層に入れても効果の64%が残るので、「前半の層を楽にする」だけでは説明しきれないと見ている。表を切った実験でも MATH が36%まで落ちるので、「知識は表にある」も弱い根拠。
- **採用：** DeepSeek-V4（arXiv 2606.19348）は使わず、今後探る方向に挙げている。[Marin の記事](../sources/marin-moe.md)も見送っている。

## 見方が変わりそうな条件

- MoE を入れる場合。論文の結果は MoE の上のもの。
- 2トークンの表を今の規模で測り、効果が見込みより大きかった場合。
- BPB 以外の物差しに変える場合。追試では、ベンチマークは上がって BPB は下がった。

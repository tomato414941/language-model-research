# 候補

[基準のモデル](../experiments/baseline.md)を、同じお金で良くする候補の一覧。上にあるものほど優先する。2026-11-01 時点の仮の順番で、ほとんどは今の規模で測っていない。結果が出たり新しい候補が見つかったりしたら書き換える。

- 候補は種類で外さない。モデルや学習法のほか、速度、料金、データ、課題設定も入れる。効きにくそうなものも、理由を添えて後回しにするだけで消さない。
- 順番は、効果の見込み、根拠の強さ、手間で決める。大きくても根拠が弱いもの、実装が重いものは下にある。
- 数字は同じお金で BPB が下がる割合の粗い見込み。重なるものもあるので足し算はできない。「不明」は数字の根拠がないもの。
- 「まず試す」より下は、大半が過去のメモや要旨からの判断で、元の論文を読み切っていない。決める前に読む。

## 今の規模では効きにくそうな候補

| 候補 | 後回しの理由 |
|---|---|
| Engram の完全な形 | 小さい規模では2トークンの表と差がない |
| Screening | 主な利点は長い文脈 |
| H-Net | 構造が大きく変わる。比較が少ない |
| CompleteP | 効くのは深いモデル |
| Per-layer embeddings | 中身を未確認 |
| 埋め込みの分離 | 比較の記録がない |
| Sampled softmax | 語彙が小さいので得が少ない |
| 文書の間の注意を切る、長い文書の分割 | ほぼ差がない |
| MTP、SwiGLU、LeakyReLU²、XSA、直交初期化 | nanochat では効かないか、時間で負けた |
| FP8 | 12層ではかえって遅い |
| GQA | 主に推論のための手法 |
| RETRO 型の検索 | 2〜6%悪化の見積もり（DB を巨大にしない限り） |
| 層を足して続きを学習する | 同じお金での比較がない |

## BPB では測れない候補

課題設定を変えるときに、改めて順番を決める。

- 指示学習（SFT）、好みの学習（APO）、指示用のデータ
- 正解で強化学習する（RLVR）
- ツール、ハーネス、検索で事実を引く力
- 重みにプログラムを組み込む（Qwenputer）
- 推論の費用も数える形（Train-to-Test、小さいモデルを長く学習する）
- 日本語、複数の言語、日本語の評価
- 第2の規模で効果を確かめる

個別の見方は同じ `topics/` にあり、ほかの多くは `language-model` の [`topics/`](https://github.com/tomato414941/language-model/tree/main/docs/research/topics) にある。

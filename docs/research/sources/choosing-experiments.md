# Choosing experiments to accelerate collective discovery

Rzhetsky、Foster、Foster、Evans（PNAS 2015、doi:10.1073/pnas.1509757112）。

**本文は取得できず、検索の要約と Kellogg Insight の解説でしか読んでいない。**

科学を、実験で発見していくネットワークとして模型にした。多くの研究者の選び方は、分野の初期には効率的だが、成熟すると全体の進歩を遅らせる。より冒険することと、失敗の公表を増やすことを勧めている。解説によると、最適な戦略はグラフの50%を見つけるのにランダムな戦略の10倍近く効率的。

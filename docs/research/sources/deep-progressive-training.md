# Deep Progressive Training

Zhiqi Bu（arXiv 2511.04981、ICML 2026 の題は Scaling Depth Capacity via Zero/One-Layer Model Expansion）。

0層か1層のモデルを学習し、学習の後半で一度に目標の深さへ広げる。

- 新しい層はランダムな初期値が既定。1層のときはコピーも効く。0初期化は学習できないので使わない。
- 広げるのは学習率が一定の期間の中で、学習率の予定は WSD。cosine では遅く広げると追いつかない。広げる前後でハイパーパラメータは同じ。
- 学習の80%（0.8T）まで広げるのを遅らせられる。多段階に広げる必要はないとする。
- 結果：GPT-2 で計算を約80%節約、約5倍の加速（60層、70億と比べて）。ICML の要旨では LLaMA3 と DeepSeekV3 のスケーリング則で計算の効率が3〜5倍で、大きいほど差が開く。最終の検証損失の差は1.24億で0.5%未満、70億で0.2%未満。
- オプティマイザは Muon-NSGD（行列は Muon、それ以外は正規化した SGD で、学習率は1つ）。AdamW より良いとする。
- 小さいモデルの計算を数えない比較は速さを過大に見せると指摘している。
- 下流の点の結果はない。

1.24億の条件：OpenWebText、文脈1,024、512本（約52万トークン）、約60万更新で48万更新目に広げる。単純に掛けると約3,100億トークン、1パラメータ約2,500トークン（自分たちの計算）。0層は3,900万、1層は4,600万パラメータで、大半は埋め込み。論文のパラメータで数える式なら、節約はこの大きさで約5割（自分たちの計算）。広げたあとの混ざる時間は、7B で約4万更新としている。

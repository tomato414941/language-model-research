# μ-Transfer の論文

Lingle、An Empirical Study of μP Learning Rate Transfer（arXiv 2404.05728）。学習率を別の規模に持ち越せるかを調べた研究で、モデルは最大10億パラメータ、1,900億トークン。

- 出力の初期値を小さくする μP の設定で、RMSNorm の重みの有無を比べた（4.2.3）。一番大きいモデルで、学習率が最適のとき、重みは品質を下げた。μP でも重みのない形が、重みのある普通の形を上回った（4.5）。
- 重みがあると、学習率を別の規模に持ち越しにくい。

読んだのは4.2.3の本文と、モデルの条件の部分。表4の数字は読んでいない。

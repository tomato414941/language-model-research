# Olmo Hybrid

Olmo チーム（arXiv 2604.03444、2026-04）。Gated DeltaNet と全注意の混成を、公開のスケーリング則の形で調べた。

- 7B を最大6兆トークン。OLMo 3 7B と比べ、Common Crawl の同じ loss に要るトークンが35%少なく、同じ MMLU には49%少ない。形を調整してパラメータ数と学習の速さを OLMo 3 に合わせている。
- スケーリング則から、同じ大きさでのトークンの節約は1Bで約1.3倍、7Bで1.68倍、30Bで1.82倍、70Bで1.89倍。
- 名目1億パラメータの比較（Math、Code、QA の loss）は、Transformer 0.981、0.804、1.326。Gated DeltaNet 3:1 は0.934、0.752、1.271。ただし実際のパラメータは約1億300万と1億3,000万で揃っていない。Mamba2 は Transformer とほぼ同じ。

読んだのは要旨、導入、主な表と図の説明。全文は読んでいない。

# xIELU

Huang、Schlag、Deriving Activation Functions Using Integration（arXiv 2411.13010）。

- 活性化関数を勾配の形から作る。正の側は ReLU² と同じく勾配が直線的に増え、負の側は負の勾配を持てる。
- xIELU は正の側が `αp x² + 0.5x`、負の側が `αn (e^x − 1) − αn x + 0.5x`。αp、αn は層ごとに学習する値で、softplus で範囲を決める。xIPReLU は負の側も `αn x² + 0.5x` にした軽い形。
- ReLU² や GELU より勾配の点で良いと論じているが、理由の説明は仮説で、もっと厳密な枠組みが要るとしている。

Llama の形で、RMSNorm、RoPE、AdamW、FineWeb Edu。重みと計算は、GLU でない MLP の中の幅を1.5倍にして揃えている。損失の差は自分たちの計算。

**主な比較（文脈4,096、1,250億トークン、1パラメータ約114トークン）：**

| 活性化関数 | 11億の検証の損失 | 30億の検証の損失 |
|---|---|---|
| SwiGLU | 2.353 | 2.273 |
| ReLU² | 2.337 | |
| xIPReLU | 2.327 | |
| xIELU | 2.323 | 2.258 |

誤差は ±0.004 くらい。ReLU² から xIPReLU で −0.43%、xIELU で −0.60%。学習の初めのうちは xIELU が SwiGLU より悪く、200億トークンで追いつく。

**項目の比較（11億、文脈1,024、40億トークン、1パラメータ約3.6トークン）の perplexity：**

| 活性化関数 | perplexity |
|---|---|
| xIELU | 17.52 |
| xIPReLU | 17.52 |
| SwiGLU | 17.58 |
| xSiLU | 17.91 |
| ReLU² | 18.12 |
| SiLU | 18.57 |

SiLU から ReLU² で −0.84%、ReLU² から SwiGLU で −1.04%、xIELU で −1.16%。

**1回の更新の時間（11億、GH200 4枚）：**

| 活性化関数 | ミリ秒 |
|---|---|
| ReLU² | 534 |
| SiLU | 540 |
| xIPReLU（最適化なし） | 542 |

- 下流の評価は30億で SwiGLU 39.6、xIELU 39.7 でほぼ同じ。課題によって勝ち負けが違う。
- 限界として、速さは専用のカーネルが要ること、もっと大きいモデルでの確認、低い精度で学習するには変更が要るかもしれないことを挙げている。Muon や小さいモデルの結果はない。

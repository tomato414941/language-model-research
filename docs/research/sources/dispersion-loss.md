# Dispersion Loss

Liu ら、Dispersion Loss Counteracts Embedding Condensation and Improves Generalization in Small Language Models（arXiv 2602.00217、ICML 2026）。

## 集まる現象

- 同じ文のトークンのベクトルどうしのコサイン類似度が、1の近くに集まる（Definition 1.1）。各層を通ったあとのベクトルで、文の中の全部の組で測る（§2.2）。
- GPT-2 や Qwen3-0.6B のような小さいモデルで強く、GPT2-xl や Qwen3-32B のような大きいモデルでは起きにくい。GPT-2 の形で大きさを変えた実験でも、大きいほど集まりにくい（§3.1.2）。どの大きさで消えるかは示していない。
- 大きいモデルからの蒸留では直らないとしている。

## 方法

- 損失 `log Σ_{i≠j} exp(−arccos(cos(z_i, z_j)) / (π τ))` を、文ごとのトークンのベクトルで計算し、層をまとめて、次のトークンの損失に重み0.1で足す（τ=1、§3.4、§4.2）。前の層より後ろの層にかけるほうが効く（§4.2）。
- 計算は1つの束で `O(N²F)`（N は文の長さ、F は幅）。トークンを間引いてもよい（§3.4）。

| モデル | 通常 | 分散の損失あり |

| GPT-2 | 34.95 ± 0.11 | 35.61 ± 0.12 |
| GPT-2-m | 38.55 ± 0.18 | 39.35 ± 0.15 |
| Qwen3-0.6B | 45.93 ± 0.37 | 47.45 ± 0.16 |
| Qwen3-1.7B | 54.57 ± 0.17 | 55.68 ± 0.21 |

- 上は学習済みのモデルの続きを2億トークン読んだ結果（wikitext-103、3つの種）で、10課題の平均。時間は1.03〜1.05倍（Table 2、A100 の時間）。
- ゼロからの学習は、Qwen3-0.6B を C4 で1,560億トークン（640枚の GPU）。34.84→36.01（PIQA +4.0、TruthfulQA +7.4、Table 5）。ばらつきは示していない。
- 検証の損失や perplexity は報告していない。

# Delphi

Open Athena の記事、Scaling Laws That Extrapolate 300× Past the Fit（2026-05、https://www.openathena.ai/blog/delphi/）。Marin の最初のスケーリングの一式。

- 3e18〜3e20 の各計算量で、モデルの大きさとトークン数を変えて最適な点を探し、その点から 1e21、1e22、1e23 を予測して確かめた。形は Qwen 3、文脈4,096。
- 3つの種の差は約0.1%で、予測の95%信頼区間の約10分の1。
- 最適から外れる損も見積もっている。10倍長く学習すると、同じ loss に計算量が約6倍要る。ただし、もとのデータは2倍までで、著者もこの数字は信頼が低いとしている。
- 推論の費用を数えると、多くの組織は長めに学習する側に寄る。Llama 3 8B は最適の約90倍、OLMo 3 7B は約40倍のトークンで学習しているとしている。

読んだのは本文の大部分。図の値は読んでいない。

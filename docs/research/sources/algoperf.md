# AlgoPerf

Kasimbeg ら、Accelerating neural network training: An analysis of the AlgoPerf competition（arXiv 2502.15015、2025-02）。

- 学習アルゴリズムだけの改善を、固定したハードウェア、複数の課題での到達時間で比べる競技。第1回は10チームから18件。
- 設定の探索範囲を提出する部門の1位は、Distributed Shampoo。実時間で比べても Adam などに勝った。
- 調整を一切しない部門の1位は、Schedule Free AdamW を元にした提出。
- 上位の提出は、課題の変更に強かった。

読んだのは要旨だけ。

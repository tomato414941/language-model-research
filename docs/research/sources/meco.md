# MeCo

Gao、Wettig、He、Chen、Metadata Conditioning Accelerates Language Model Pre-training（arXiv 2501.01956、ICML 2025）。

学習の最初の90%は文書の頭に URL のドメイン（例：`en.wikipedia.org`）を付け、最後の10%は付けずに学習する。メタ情報のトークンには損失をかけない。

## 条件

- Llama 型、Llama-3 のトークナイザ、DCLM-Baseline。6億、16億、30億は1,600億トークン、80億は800億トークン。
- 文脈8,192に詰める。AdamW（β 0.9、0.95）、学習率は最大3e-3（80億は5e-4）、準備5%のあと cosine で最大の10%まで。weight decay 0.033（80億は0.1）、1回の更新は400万トークン。
- 1回ずつの学習。1つの途中の重みから3回続けたときの揺れは、平均の点で±0.1（表13）。

## 結果

| 大きさ | 普通 | MeCo |
|---|---|---|
| 6億 | 51.5 | 51.7 |
| 16億 | 55.7 | 56.7 |
| 30億 | 59.2 | 59.8 |
| 80億 | 57.8 | 58.4 |

- 10課題の平均（表17）。16億の MeCo は、普通に2,400億トークン学習したもの（56.7）と同じで、これが「要るデータが33%減」の根拠（表1）。
- perplexity は、16億で普通が13.2、MeCo が13.3（表1）。論文は、perplexity は下流の点と相関しないとしている。
- 著者は、大きいモデルほど得が大きいように見えるが、傾向はばらつくとしている。

## メタ情報の種類（16億、表5）

ドメイン56.7、URL 全体56.8、URL の末尾（org など）56.2、上位0.2%の URL だけ56.4、上位2%だけ56.3、ハッシュにした URL 56.7、モデルが作った話題56.6。ハッシュでも同じなので、意味より文書のまとまりが効いているとしている。話題を作るのに約1,500 GPU 時間かかった。

## 最後の期間

- メタ情報を最後まで付けると、付けずに使ったときに50.3まで下がる（表4）。
- 最後の期間は10%で56.7、20%で56.8、30%で56.2（表14）。
- 90%を URL つき、10%を普通の文書として混ぜて学習すると56.4で、2段階より低い。

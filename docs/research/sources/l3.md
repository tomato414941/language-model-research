# L³: Large Lookup Layers

Tseng and De Sa (arXiv 2601.21461, ICML 2026).

A layer that holds a set of embeddings chosen by the token's ID, which the hidden state attends to. The routing depends only on the token, so the rows to look up are known in advance.

## How it works

- Each token t has d_t keys (as wide as the hidden state) and values (width 512 or 1024). d_t is set from frequencies with LZW: 710,000 in total, from 1 to 512 per token.
- `L³(x, t) = W_mix [LayerNorm(W_up(V_tᵀ Softmax(K_t x))); x]`. It attends with a softmax over all of that token's embeddings, concatenates the result with the original x, and mixes them. There is no gate.
- It does not replace the MLP but is added between layers. With 1 layer, at layer 4; with 2 layers, at layers 4 and 16.
- AdamW (weight decay 0.1), with a cosine learning rate peaking at 3e-4. Initialization is the same as for Llama's linear layers. Whether the table alone got a separate learning rate is not stated.
- The vocabulary is SuperBPE with 180,000 tokens, at 4.7 bytes per token on average on FineWeb-Edu.

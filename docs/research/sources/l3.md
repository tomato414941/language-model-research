# L³: Large Lookup Layers

Tseng、De Sa（arXiv 2601.21461、ICML 2026）。

トークンの番号で決まる埋め込みの組を持ち、隠れ状態がそれに注意をかける層。経路はトークンだけで決まるので、引く行が先に分かる。

## 仕組み

- トークン t ごとに d_t 個のキー（幅は隠れ状態と同じ）と値（幅512か1024）を持つ。d_t は LZW で頻度から決め、全体で71万個、1トークンあたり1〜512個。
- `L³(x, t) = W_mix [LayerNorm(W_up(V_tᵀ Softmax(K_t x))); x]`。そのトークンの埋め込みの全部にソフトマックスで注意をかけ、元の x とつないで混ぜる。ゲートはない。
- MLP は置き換えず、層の間に足す。1層なら4層目、2層なら4層目と16層目。
- AdamW（weight decay 0.1）、学習率は最大3e-4の cosine。初期化は Llama の線形層と同じ。表だけ別の学習率にしたかは書かれていない。
- 語彙は SuperBPE の18万で、FineWeb-Edu では1トークン平均4.7バイト。

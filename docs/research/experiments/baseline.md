# 基準の nanoGPT を H100 で学習した

2026-10-31 に、そのままの nanoGPT を ClimbMix で5億トークン学習し、種を変えて2回動かした。3回目は途中で止めた。

## 条件

- 機械：Vast.ai の日本の H100 SXM 80GB を1枚、$2.41/時。ドライバ 615.71.09。
- イメージ：`pytorch/pytorch:2.15.0-cuda13.2-cudnn9-runtime`（torch 2.15.0+cu132）。
- モデル：12層、幅768、12ヘッド、文脈1,024、語彙8,192、9,125万パラメータ（`configs/baseline.py`）。
- 学習：954回の更新、1回524,288トークン（1回64本を8回足す）、計約5億トークン。bf16、torch.compile。
- データ：ClimbMix（`karpathy/climbmix-400b-shuffle`、`915333b`）。語彙8,192の BPE をこのデータで学習し、20億トークンを用意した。検証は最後のファイル（6,337万トークン）。
- 採点：英語6つのベンチマークの全問（30,470問）の正解の BPB と、検証データの最初の約105万トークンの BPB。

## 時間と費用

| 段階 | 実測 |
|---|---|
| 借りてから使えるまで | 162秒 |
| データの転送（3.9GB、処理用の機械から中継） | 197秒 |
| パッケージの追加 | 8秒 |
| 学習（種1、種2） | 830秒、808秒 |
| うち最初の更新まで（compile など） | 約31秒 |
| 1回の更新 | 約0.83秒（約63万トークン/秒） |
| 採点（種1、種2） | 20秒、18秒 |
| 重みの保存 | 2秒 |

借りていた約41分で $1.97（Vast の残高の差）。GPU の使用率は学習中99〜100%、メモリは約28GB、消費電力は約690W。

## 点

| | 種1 | 種2 | 差 |
|---|---|---|---|
| 検証データの BPB | 1.2536 | 1.2571 | 0.0035 |
| 検証の損失（`train.py`、20回の抜き出し） | 3.4646 | 3.4834 | 0.019 |
| 正解の BPB（6つの平均） | 1.6921 | 1.6700 | 0.022 |
| MMLU（14,042問） | 1.953 | 1.990 | 0.037 |
| ARC-Easy（2,376問） | 1.769 | 1.716 | 0.053 |
| ARC-Challenge（1,172問） | 1.736 | 1.705 | 0.030 |
| HellaSwag（10,042問） | 1.292 | 1.296 | 0.004 |
| PIQA（1,838問） | 1.615 | 1.636 | 0.021 |
| SciQ（1,000問） | 1.787 | 1.676 | 0.111 |

同じ問題どうしの差の標準誤差は 0.0006〜0.0083 で、種による差よりずっと小さい。問題数ではなく種の違いが、ばらつきを決めている。種は2つだけなので、ばらつきの大きさは粗い。

参考：OpenAI の GPT-2（語彙50,257、1.2億パラメータ）を同じベンチマーク200問ずつで採点すると、正解の BPB の平均は 1.450（採点ソフトで測定。問題が違うので直接は比べられない）。

## 起きたこと

- イメージの Python は `pip` の追加を断るので、`--break-system-packages` が要った。
- `train.py` の出力はファイルに書くと溜まるので、進み具合が見えなかった。`python -u` に直した。
- 3回目を止めるコマンドが自分自身を止めて失敗し、機械を消すまで約6分動いた。

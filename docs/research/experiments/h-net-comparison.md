# H-Net と BPE のモデルを同じ費用で比べる（日本語と英語）

2026-11-04 に、測る前に決めた。H-Net が同じ費用で BPE のモデルより良いかを、日本語と英語で比べる。外側の層を Mamba-2（論文の形）、Mamba-3、Gated DeltaNet にした3通りを測る。コードと設定は `h-net/` にある。

## 条件

- 機械：Vast.ai の H100 SXM 80GB を1枚。イメージは基準と同じ。
- 費用：基準（baseline.md）を同じ機械で短く動かし、954回の更新にかかる時間を出す。各モデルの更新の回数は、その時間で読める回数にする（speed.py と同じ計算）。H-Net は区切りを6バイトごとに固定して時間を測る。学習の始めは約2バイトごとに区切るため、短い計測では本番より遅く見える。本番の学習時間は記録し、決めた時間とずれたら書く。
- データ：`language-model` の v6 のコーパスの日本語と英語。ClimbMix は非商用のライセンスなので使わない。安定期と減衰期のそれぞれで、両方の言語の文書を1つの順に混ぜて25億バイトまで取る。2つの言語はトークン数で半分ずつ。学習率が下がり始める所で減衰期のデータに替える。
- BPE のモデル：2番目の組（second-bundle.md）の形。トークナイザは prepare.py と同じ作り方で、語彙8,192を安定期の文章で学習し直した。1回の更新で512行、1行1,024トークン。
- H-Net：本体は2番目の組と同じ10層・幅640で、まとまりの上で動く。value embeddings はトークンごとの表なので外した。外側は幅512で、エンコーダとデコーダが4層ずつ。区切りの目標は6バイト、比率の損失の重みは0.03（論文と同じ）。1行は、BPE の1,024トークンが平均で持つバイト数。1回の更新で512行（64行を8回）。外側の層の学習率は未調整で、AdamW の他の重みと同じ0.0044。
- 採点：各言語の検証の文章での BPB。v6 の安定期の検証の文書の頭を、両方のモデルが丸ごと読める長さで、各言語200万バイトまで使い、同じ文章どうしで比べる。harness.py の英語6課題と日本語3課題の、正解率と正解の BPB。

## 結果を見る前に決めた読み方

- 言語ごとに、検証の BPB と正解の BPB の平均を BPE のモデルと比べる。検証の BPB で0.3%（scoring.md）、正解の BPB の平均で1.3%（second-bundle.md）を、種による揺れとする。それを超えて低ければその言語で H-Net の勝ち、超えて高ければ負け、その間は差が測れないと読む。
- 測る前の予想は、3通りとも両方の言語で負け、日本語の差は英語より小さい。外側の層は、Gated DeltaNet と Mamba-3 が Mamba-2 より良い。

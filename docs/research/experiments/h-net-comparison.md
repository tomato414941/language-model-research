# H-Net と2番目の組を同じ費用で比べる（日本語と英語）

2026-11-04 に、測る前に決めた。H-Net が同じ費用で BPE のモデルより良いかを、日本語と英語で比べる。外側の層を Mamba-2（論文の形）、Mamba-3、Gated DeltaNet にした3通りを測る。コードと設定は `h-net/` にある。

## 条件

- 比べる相手：research が ClimbMix をやめて作り直す、`language-model` と同じ日英の出典のデータで、学習し直した2番目の組（second-bundle.md の形）。H-Net の側では学習しない。
- データ：同じデータの文書を、同じ順のままバイトに直して読む（bytes_from_tokens.py）。安定期と減衰期の2つのデータで、学習率が下がり始める所で替える。1行は、BPE の1,024トークンが平均で持つバイト数。
- 機械：Vast.ai の H100 SXM 80GB を1枚。イメージは基準と同じ。
- 費用：基準（baseline.md）を同じ機械で短く動かし、954回の更新にかかる時間を出す。各モデルの更新の回数は、その時間で読める回数にする（speed.py と同じ計算）。H-Net は区切りを6バイトごとに固定して時間を測る。学習の始めは約2バイトごとに区切るため、短い計測では本番より遅く見える。本番の学習時間は記録し、決めた時間とずれたら書く。
- H-Net：本体は2番目の組と同じ10層・幅640で、まとまりの上で動く。value embeddings はトークンごとの表なので外した。外側は幅512で、エンコーダとデコーダが4層ずつ。区切りの目標は6バイト、比率の損失の重みは0.03（論文と同じ）。1回の更新で512行（64行を8回）。外側の層の学習率は未調整で、AdamW の他の重みと同じ0.0044。
- 採点：2番目の組と同じものを同じ文章で測る。検証の BPB は scoring.py と同じ行（val.bin の最初の2²⁰トークン、1行1,024トークン）のバイトを読み、scoring.py が数えるバイト数で割る。harness.py の英語6課題と日本語3課題の、正解率と正解の BPB。

## 結果を見る前に決めた読み方

- 検証の BPB と、言語ごとの正解の BPB の平均を、2番目の組と比べる。検証の BPB で0.3%（scoring.md）、正解の BPB の平均で1.3%（second-bundle.md）を、種による揺れとする。それを超えて低ければ H-Net の勝ち、超えて高ければ負け、その間は差が測れないと読む。
- 測る前の予想は、3通りとも負け、日本語の差は英語より小さい。外側の層は、Gated DeltaNet と Mamba-3 が Mamba-2 より良い。
